# مدرسة نخل الوقفية للقرآن الكريم — منصة تعريفية وتبرعات

الواجهة الأمامية (المرحلة الأولى) لمنصة رقمية تعرّف بمدرسة نخل الوقفية للقرآن الكريم، وتعرض مرافقها وأنشطتها، وتوفّر وسيلة سهلة للتبرع.

## الشاشات

| المسار | الشاشة |
|---|---|
| `/` | الشاشة الافتتاحية |
| `/home` | الصفحة الرئيسية |
| `/gallery` | معرض الصور (تصنيفات + عارض مكبّر) |
| `/map` | خريطة المدرسة التفاعلية (تكبير، سحب، بطاقة تفاصيل لكل مرفق) |
| `/donate` | التبرع (بيانات الحساب مع النسخ + رمز QR + فتح تطبيق البنك) |

## التقنيات

React 18 + TypeScript + Vite · Tailwind CSS 4 · Framer Motion · React Router · PWA (vite-plugin-pwa) · صور WebP

## التشغيل محلياً

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # بناء نسخة الإنتاج في dist/
npm run preview  # معاينة نسخة الإنتاج
```

## تعديل المحتوى

كل المحتوى في مجلد `src/data/`:

- `site.ts`: الاسم، والنصوص، و«عن المدرسة»، والبرامج، وبيانات التواصل
- `gallery.ts`: صور المعرض وتصنيفاتها
- `facilities.ts`: مرافق الخريطة، ووصفها، ومواقع الدبابيس
- `donation.ts`: البيانات البنكية (**تجريبية حالياً**). رمز QR يُولَّد منها تلقائياً. بعد إدخال البيانات الحقيقية غيّر `isPlaceholder` إلى `false`.

**الصور:** ضع صورك في `public/images` بنفس الأسماء، ولكل صورة نسختان: `name.webp` بعرض 1200 تقريباً، و`name-sm.webp` بعرض 600.

## النشر

- **Netlify:** الإعدادات جاهزة في `netlify.toml` (أمر البناء `npm run build`، ومجلد النشر `dist`).
- **Vercel:** الإعدادات جاهزة في `vercel.json`، ويتعرّف Vercel على Vite تلقائياً.

## المرحلة القادمة

لوحة تحكم للإدارة، وربط Supabase لإدارة الصور والمحتوى، ونظام لتتبع التبرعات، والإشعارات.
